# ✦ Jogo da Velha (Portugol)

Projeto acadêmico desenvolvido em dupla como **trabalho final da disciplina de Algoritmos** durante o curso **Técnico em Informática da CEDAF/UFV**.

O projeto consiste na implementação do tradicional **Jogo da Velha** utilizando **Portugol**, com o objetivo de aplicar conceitos fundamentais de lógica de programação, programação estruturada e manipulação de matrizes.

Este foi um dos meus primeiros contatos com programação e lógica de algoritmos, representando uma etapa importante na construção da minha base em desenvolvimento de software e resolução de problemas.

---

## ✧ Sobre o projeto

Este trabalho foi desenvolvido para consolidar os conhecimentos adquiridos ao longo da disciplina de Algoritmos, abordando conceitos essenciais para a formação em programação.

A aplicação permite que dois jogadores disputem partidas em um tabuleiro 3x3, realizando o controle das jogadas, validação de posições, identificação de vitórias e empates, além do registro de estatísticas ao final das partidas.

---

▸ Desenvolver algoritmos utilizando Portugol

▸ Trabalhar com estruturas condicionais e de repetição

## ✧ Funcionalidades

▸ Alternância automática entre os turnos

▸ Validação de posições ocupadas

▸ Verificação de vitória por linhas

▸ Verificação de vitória por colunas

▸ Verificação de vitória por diagonais

▸ Detecção de empate

▸ Registro de vitórias dos jogadores

▸ Cálculo de porcentagem de vitórias

---

## ✧ Como executar

Para executar o projeto é necessário utilizar um ambiente compatível com **Portugol**, como o **Visualg**.

▸ Baixe ou clone este repositório

▸ Abra o arquivo `.alg` no Visualg

▸ Execute o algoritmo

▸ Escolha a opção para iniciar uma partida

▸ Informe a linha e a coluna desejadas para cada jogada

▸ Continue jogando até que haja um vencedor ou ocorra empate

---

## ✧ Estrutura do jogo

▸ Jogador 1 utiliza o símbolo **X**

▸ Jogador 2 utiliza o símbolo **O**

▸ Vence quem completar uma linha, coluna ou diagonal

▸ O empate ocorre quando todas as posições são preenchidas sem vencedor

▸ Ao encerrar a execução são exibidas estatísticas das partidas realizadas
